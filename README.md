# Bitcoin Market Sentiment vs Trader Performance Analysis

## Objective

This project analyzes the relationship between Bitcoin market sentiment (Fear & Greed Index) and trader performance using Hyperliquid historical trading data.

## Methodology

* Data Cleaning
* Date Standardization
* Dataset Merging
* Exploratory Data Analysis
* Profitability Analysis
* Win Rate Analysis
* Trade Size Analysis
* Risk Analysis
* Correlation Analysis

## Key Findings

* Extreme Greed periods showed the highest average profitability.
* Fear periods had larger average trade sizes.
* Extreme Fear periods exhibited higher volatility.
* Market sentiment significantly influences trader behavior and performance.
